# Demo video credits

What the demo video is made of, and where each part comes from.

| Part | Source |
|---|---|
| App screens | Real captures of this project, from `scripts/local/judge.sh` with no key |
| Live scene | Screen recording of a live run with a Meta key, in [`docs/evidence/judge-run-20261103`](evidence/judge-run-20261103/README.md) |
| JSON and SAM values | Real model output, from `scripts/local/recordings/demo.json` |
| Illustrations and the flat owl | Drawn for this video |
| Narration | Synthetic voice, Kokoro (`bm_george`), generated on device |
| Music and sound effects | Synthesized for this video |
| WhatsApp, Facebook and Instagram logos | [Simple Icons](https://simpleicons.org), CC0. The marks belong to Meta |

Mario, Carlos and Northside Plumbing are a fictional example. The sample leak video is generated, from a `muse-image-1.0` picture.
